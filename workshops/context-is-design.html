WORKSHOPStandards the Agent Follows
01 Write the Design System
Last week’s values sit in a finished task. A rule every page follows belongs where every session reads it. Paste:
prompt to Claude 
Read my site's CSS and tasks/done/02-type-grid-color.md. Write
design-system.md at the root of this folder: every color, font, size
and grid value named once as a CSS variable, each with one line on
when to use it. Show it to me. Then make the site's CSS use those
variables instead of raw values.
  • A rule says when: “accent: links, and one highlight per page”, not only a hex value.
02 Point CLAUDE.md to It
prompt to Claude 
In CLAUDE.md, replace any type, grid or color values with one line:
every page follows design-system.md. The values live only there.
  • One home for each fact. Change the accent color in one file and every page follows; two copies would one day disagree.
03 Audit CLAUDE.md
Four weeks of sessions have each added a line. Paste:
prompt to Claude 
Audit CLAUDE.md. List every line that is stated twice, out of date,
something you could learn by reading the files, or phrased as what
not to do. For each, propose a cut or a rewrite. Apply nothing until
I approve.
Before you approve a cut Would a new session still do this right without the line?
04 Test with a Fresh Session
Start a new session in the same folder and paste:
prompt to Claude 
Add a footer to every page with my name, the year and a link to my
GitHub. Then tell me which rules you followed and where they are
written.
What to look for The answer names design-system.md. If the footer uses a color or size that is not in the system, the gap is in the files: fix the file, then ask again.
05 Hand It In
prompt to Claude 
Commit and push. Tag the latest commit week-04 and push the tag.
Give the link to the instructor. It will be opened in class.
Feeds forwardNext week, agents you brief build new pages against this system, and the lead session reviews them against it.
